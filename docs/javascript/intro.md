# JavaScript - Referência Técnica

Bem-vindo à referência técnica de JavaScript! Este guia cobre conceitos fundamentais da linguagem, organizados para facilitar consultas rápidas e aprendizado progressivo.

## Estrutura do Guia

- **Tipos de Dados**: Symbol, BigInt, typeof e mais
- **Strings**: Manipulação, concatenação e métodos
- **Console**: Logging e debugging
- **Assincronia**: async/await, promessas e tratamento de erros
- **Programação Orientada a Objetos**: Classes, encapsulamento, métodos estáticos
- **Operadores**: Spread e Rest

Cada seção inclui explicações claras, exemplos práticos e referências cruzadas para conceitos relacionados.
