
### 3️⃣ Vá para Pages

```
No menu lateral esquerdo → Pages
```

### 4️⃣ Configure Build and Deployment

```
Source:     Deploy from a branch
Branch:     gh-pages
Folder:     / (root)
```

Clique em **Save**

### 5️⃣ Pronto! 🎉

GitHub Actions vai:
- ✓ Detectar mudanças
- ✓ Fazer build automático
- ✓ Publicar site

## 🆘 Algo Deu Errado?

### Site não aparece?

1. Aguarde 5 minutos
2. Limpe cache (Ctrl+Shift+Delete)
3. Verifique Actions em GitHub

### Build falhou?

1. Vá em Actions
2. Clique no workflow falhado
3. Veja logs de erro
4. Corrija e faça novo push

### Página em branco?

1. Verifique se Pages está ativado
2. Confirme que branch é `gh-pages`
3. Confirme que folder é `/ (root)`
